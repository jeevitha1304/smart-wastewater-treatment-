PROJECT INFORMATION

About this system

Web-based wastewater laboratory data and decision-support prototype.

Workflow

Sample registration → lab data entry → reference-range checks → treatment recommendation → post-treatment entry → comparison → reuse decision support.

Parameters

pH, turbidity, COD, BOD, TDS, electrical conductivity (EC), and dissolved oxygen (DO).

Limitations

This application does not physically treat wastewater or control equipment. Default ranges are demonstration settings, not universal regulatory limits. Actual reuse decisions require applicable local standards, required tests, and qualified approval.

Technologies

Python, Flask, SQLite, HTML, CSS, JavaScript.
